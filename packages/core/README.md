# @mutant-engine/core

The body model of [mutant-engine](https://github.com/smoreg/mutant-engine): a creature as a graph, mutation, derived stats, life, surgery and turn-based combat. Pure functions, seeded randomness, no DOM.

See the [main README](https://github.com/smoreg/mutant-engine#readme). Version 0.1: the API will change before 1.0.
