# @mutant-engine/view

Layout and pictures for [@mutant-engine/core](https://www.npmjs.com/package/@mutant-engine/core) bodies: one layout for sprite and graph, SVG silhouettes, pixel sprites, a dependency-free PNG encoder.

See the [main README](https://github.com/smoreg/mutant-engine#readme). Version 0.1: the API will change before 1.0.
